# Customer Churn Analysis Project

## 📌 Project Overview
Customer churn is a critical challenge for subscription-based businesses. This project analyzes a dataset of **500+ customer records** to identify churn drivers, build predictive models, and recommend actionable retention strategies. The goal is to demonstrate how **data-driven insights** can reduce churn and improve long-term customer loyalty.

---

## 🎯 Objectives
- Identify key factors contributing to customer churn.
- Build predictive models to estimate churn probability.
- Segment customers into risk groups for targeted interventions.
- Provide a **business implementation plan** to reduce churn by 10–15%.

---

## 🛠️ Technical Workflow
The project follows a structured workflow:

1. **Data Cleaning & Preparation**  
   - Convert numeric fields, handle missing values.  
   - Encode categorical variables.  
   - Save outputs into `data/cleaned_data.csv`.

2. **Exploratory Data Analysis (EDA)**  
   - Churn distribution analysis.  
   - Monthly charges vs churn.  
   - Correlation heatmap.  
   - Tenure vs churn survival-style curve.

3. **Advanced Analysis**  
   - Logistic Regression & Random Forest classification.  
   - ROC curve evaluation.  
   - Feature importance ranking.  
   - KMeans clustering for customer segmentation.

4. **Insights & Recommendations**  
   - Translate findings into actionable business strategies.  
   - Prepare executive summary, technical report, and presentation.

## 🚀 Business Implementation Plan
1. Deploy churn prediction model to flag high-risk customers.  
2. Launch targeted retention campaigns (contract incentives, payment method upgrades).  
3. Monitor churn monthly and adjust strategies.  
4. Measure success via churn reduction percentage and revenue retention.  

**Expected Impact:** Reduce churn by **10–15%**, translating into significant annual revenue retention.
